## Description

This project demonstrates advanced CSS layout techniques using Flexbox and CSS Grid.

The assignment includes navigation, cards, a grid page layout, an image gallery, and a portfolio page.

## Tasks

### Task 0 — Navigation Bar

Created a navigation bar using Flexbox. The logo is placed on the left and navigation links are placed on the right.

### Task 1 — Card Row

Created three cards using Flexbox. Each card contains an image, title, description and button. The cards have equal height, gaps and a hover effect.

### Task 2 — Grid Layout

Created a page layout using CSS Grid with a header, sidebar, main content and footer.

### Task 3 — Image Gallery

Created an image gallery with nine images using CSS Grid. The gallery contains three columns, gaps between images and a hover caption effect.

### Task 4 — Portfolio

Created a portfolio page combining CSS Grid and Flexbox. Grid is used for the main page layout, while Flexbox is used for the navigation and project cards.

## Technologies

* HTML5
* CSS3
* Flexbox
* CSS Grid
